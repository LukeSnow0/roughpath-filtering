\subsection*{Weak-error $\delta$-scaling on geometric Brownian motion}
\label{sec:gbm-weak-error}  % adjust label to match your paper

To isolate the Lyons--Victoir Wiener-cubature rate from spatial (Gaussian)
approximation error, we consider a single predict step starting from a
\emph{point mass} $P_0=0$. Spatial cubature nodes then collapse onto the
mean, so the error in the predicted moments is purely the semigroup
(path-cubature) discrepancy. We use independent geometric Brownian motions
(It\^o),
\begin{equation}
  \mathrm{d}x_i
  = \mu_i x_i\,\mathrm{d}t
  + \sigma_i x_i\,\mathrm{d}W_i,
  \qquad i=1,\ldots,d,
\end{equation}
with deterministic $x(0)=x_0$. Closed-form conditional moments provide an
exact reference (no Monte Carlo noise). In one dimension,
\[
  \mathbb{E}[x_\delta\mid x_0]
  = x_0 e^{\mu\delta},
  \qquad
  \mathrm{Var}(x_\delta\mid x_0)
  = x_0^2 e^{2\mu\delta}\bigl(e^{\sigma^2\delta}-1\bigr);
\]
the two-dimensional case used below is diagonal with independent coordinates.
Inner RK4 steps are held fixed at $64$ per interval, so the integration step
is $h=\delta/64$ and the global discretisation error is
$O(\delta^5)$, subordinate to the cubature terms we measure for small $\delta$.

Figure~\ref{fig:gbm-weak-error} reports absolute weak errors against the
assimilation interval $\delta$ on log--log axes.
\begin{itemize}
  \item \textbf{Panel (1)} (scalar GBM).
  Mean error of the Wiener-cubature filter for macro-segment counts
  $k\in\{1,3,5,7\}$ with the default degree-$m{=}5$ product formula.
  All three curves share slope $\approx 3=(m{+}1)/2$: the rate is set by the
  Lyons--Victoir degree, not by $k$.

  \item \textbf{Panel (2)} (independent $2$D GBM).
  Frobenius error $\|\widehat{P}-P\|_F$ for explicit degrees
  $m\in\{3,5,7\}$ (product Lyons--Victoir paths for $m{=}3,5$; product of
  one-dimensional four-point Gauss--Hermite straight-line lifts for $m{=}7$,
  which is sufficient here because each coordinate depends only on its own
  Brownian motion) against continuous--discrete EKF, UKF and spherical-radial
  CKF moment ODEs. Fitted slopes track $(m{+}1)/2$ (i.e.\ $\delta^2$,
  $\delta^3$, $\delta^4$). The three CD filters overlie one another: with
  \emph{linear} drift they share the same moment ODE for the drift part, and
  all freeze the diffusion at the mean, $L(t,m)$, so they inherit the same
  Gaussian-closure rate $\sim\delta^2$ and do not capture
  $\mathbb{E}[\sigma^2 x^2]=\sigma^2(m^2+P)$.
\end{itemize}

The polynomial rates are a \emph{small-$\delta$} asymptotic. Absolute moment
errors inherit the exponential growth of GBM moments
(e.g.\ $\mathrm{Var}(x_\delta)\sim e^{(2\mu+\sigma^2)\delta}$), so on a
log--log plot against $\delta$ all curves bend upward for
$\delta\gtrsim 1$; this is the scale of the state, not a failure of the
cubature. Slope fits are therefore taken on a small-$\delta$ window
(here $\delta\le 0.4$). Relative errors $|\widehat{P}-P|/|P|$ remain more
stable at large $\delta$ if that regime is of interest.
